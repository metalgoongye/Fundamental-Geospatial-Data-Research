## 작업 내역 (2026. 11. 10.)

1. **CityGML 3.0 표준 요약** — OGC 20-010(Part 1: Conceptual Model Standard, 463쪽)을 챕터별 5꼭지로 요약 → `CityGML3.0_챕터별_핵심요약.md`
2. **제안서 쉬운 버전(docx)** — 원본 `아이디어\기본공간정보 온톨로지 설계를 위한 기반연구 (제안서 초안).hwp`를, claude.ai '기본공간정보' 프로젝트의 '기본공간정보 온톨로지 기반연구' 대화 내용(쉬운 설명·팩트체크 결과)을 반영해 풀어쓴 버전 → `output\...(제안서 초안_쉬운버전).docx`
3. **담당자(5급 사무관) 검토용 hwpx** — 공간정보3법 원문(`참고자료\국내법률_공간정보3법(261110기준)`)을 직접 대조해 조문 단위 근거를 붙인 설득용 설명자료 → `output\...(담당자 검토용).hwpx`
   - 변환 경로: 이 PC의 한글(HWP)이 docx/rtf 직접 열기를 거부하므로 **HTML 작성 → 한글 COM 자동화(Open → SaveAs "HWPX")** 로 생성. 재생성 시 같은 경로 사용.

## ⚠️ 제출 전 반드시 확인할 것

1. **법령 크로스체크 필수**
   - 문서의 조문 인용(기본법 제2조 제7호·제4조·제19조·제20조·제21조, 시행령 제15조·제16조)은 2026-11-10 기준 보유 법령 파일(법률 제21065호, 대통령령 제36055호)과 대조를 마쳤으나, **제출 직전 [국가법령정보센터](https://www.law.go.kr)에서 최신 개정 여부를 반드시 재확인**할 것.
   - 「공간정보참조체계 부여·관리 등에 관한 규칙」(국토교통부령)의 **현행 여부와 실제 부여·운영 실적은 미확인** 상태 → 실태조사 항목. 이 규칙을 인용하려면 원문 확인 선행.
2. **출처 등급 구분** — `docs/출처_및_팩트체크.md` 참조. 칼럼·벤더 블로그 등 2차 자료는 보도자료·논문 등 1차 출처로 교체 권장.
3. **과거 오류 수정 이력** (재발 방지용)
   - "영국은 UPRN·USRN을 **법으로** 지정" → 틀림. 정확한 표현: "2020년 개방 후 **공공부문 공개표준**(GDS Open Standards Board 의무화, 적용 대상은 중앙정부·NHS)".
   - "OECD 36개국 중 30개국이 상호운용 체계 보유" → 숫자 틀림(30/36은 데이터 지침 제공 국가 수). 문서에서 **삭제됨**. 재인용하려면 OECD Digital Government Outlook 2026 원문에서 수치 직접 확인.
   - "시기별 지형도 간 UFID 불일치(FOSS4G Korea 2016)" → 심사 논문이 아닌 발표 슬라이드 1장 수준 → "~라는 발표가 보고된 바 있다"로 **완화 표현만 사용**.
   - "기본공간정보는 법에 '목록'으로만 존재, 식별자 제도 없음" → 틀림. 공간객체등록번호 제도는 **존재**(제2조 제7호, 제20조). 정확한 논지: "제도는 있으나 부여가 재량이고, 제19조와 미연계이며, 개별법 식별자와의 매핑·승계 책임 규정이 없음".
4. **hwpx 파일은 한글에서 열어 글꼴·여백 최종 다듬기** 권장 (HTML 경유 변환이라 세부 서식은 기본값).
